# AFL Coaches Vote Prediction

This repository contains the analysis for Individual Task 1 in
Case Studies in Data Science.

## Objective

The project investigates whether AFL player match statistics can
predict whether a player receives AFL Coaches Association votes.

## Data

Two publicly available datasets were used:
- AFL Player Match Statistics
- AFLCA Coaches Votes

The analysis uses the 2023 AFL season.

## Models

- Logistic Regression
- RBF Support Vector Machine

## Evaluation

Models were compared using:
- Accuracy
- Precision
- Recall
- F1-score
- Average Precision
- Confusion matrices

## Main Results

Logistic Regression:
- Accuracy: 0.855
- Precision: 0.502
- Recall: 0.829
- F1-score: 0.626
- Average Precision: 0.732

RBF SVM:
- Accuracy: 0.866
- Precision: 0.527
- Recall: 0.822
- F1-score: 0.642
- Average Precision: 0.690
